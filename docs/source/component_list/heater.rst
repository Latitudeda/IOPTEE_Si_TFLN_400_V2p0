Heater

heater
******************************************************
.. image:: ../images/heater.png

+------------------+----------------------+-------------+----------------------------------------------------------------------------------------+
| Parameters       |     Range            | Default     | Description                                                                            |
+==================+======================+=============+========================================================================================+
|wg_core_width     | PositiveFloat value  | 2.4         | waveguide core width.                                                                  |
+------------------+----------------------+-------------+----------------------------------------------------------------------------------------+
|wg_trench_width   | PositiveFloat value  | 3.0         | waveguide trench width.                                                                |
+------------------+----------------------+-------------+----------------------------------------------------------------------------------------+
|heater_with_pad   | Boolean value        | False       | Heater with pad or not. Set it to False to do the routing yourself.                    |
+------------------+----------------------+-------------+----------------------------------------------------------------------------------------+
|heater_width      | PositiveFloat value  | 12.5        | Heater width.                                                                          |
+------------------+----------------------+-------------+----------------------------------------------------------------------------------------+
|heater_length     | PositiveFloat value  | 200         | Heater length.                                                                         |
+------------------+----------------------+-------------+----------------------------------------------------------------------------------------+
|heater_metal_width| PositiveFloat value  | 20          | Metal width.                                                                           |
+------------------+----------------------+-------------+----------------------------------------------------------------------------------------+
|metal_line        | PositiveFloat value  | 20          | Metal line width.                                                                      |
+------------------+----------------------+-------------+----------------------------------------------------------------------------------------+


if all the parameters are set to default values, the heater will have 2 ports for waveguide connection and 6 pins for electrical connection. The port and pin information is listed below.  

+-------------------+-----------------------------+------------------------+-------------+
|     ports         | waveguide type              | position               | degrees     |
+===================+=============================+========================+=============+
| op_0              | TECH.WG.RIB1.C.WIRE         | (0.0, 0.0)             | 180         |
+-------------------+-----------------------------+------------------------+-------------+
| op_1              | TECH.WG.RIB1.C.WIRE         | (220.0, 0.0)           | 0           |
+-------------------+-----------------------------+------------------------+-------------+

+----------------------+------------------------+------------------------+-------------+
|     pins             | metal line type        | position               |  degrees    |
+======================+========================+========================+=============+
|ele1_0                |  TECH.METAL.M1.W15     |   (-10.0, 0.0)         |  180        |
+----------------------+------------------------+------------------------+-------------+
|ele1_1                |  TECH.METAL.M1.W15     |   (0.0, -10.0)         |  -90        |
+----------------------+------------------------+------------------------+-------------+
|ele1_2                |  TECH.METAL.M1.W15     |   (0.0, 10.0)          |   90        |
+----------------------+------------------------+------------------------+-------------+
|ele1_3                |  TECH.METAL.M1.W15     |   (230.0, 0.0)         |   0         |
+----------------------+------------------------+------------------------+-------------+
|ele1_4                |  TECH.METAL.M1.W15     |   (220.0, -10.0)       |  -90        |
+----------------------+------------------------+------------------------+-------------+
|ele1_5                |  TECH.METAL.M1.W15     |   (220.0, 10.0)        |   90        |
+----------------------+------------------------+------------------------+-------------+
