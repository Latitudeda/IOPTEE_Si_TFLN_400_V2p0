layers.py
==============

The layers are auto-generated by filling the ``layers.csv`` file, ``FLYLINE_MARK`` / ``ERROR_MARK`` layer are defined by **Latitudeda** for error display.

::

    class LAYER(TECH.LAYER):
        WGCORE_LN1 = Layer(PROCESS.LN1, PURPOSE.COR, 'first waveguide core')
        WGCLAD_LN1 = Layer(PROCESS.LN1, PURPOSE.CLD, 'first waveguide cladding')
        WGCORE_LN2 = Layer(PROCESS.LN2, PURPOSE.COR, 'second waveguide core')
        WGCLAD_LN2 = Layer(PROCESS.LN2, PURPOSE.CLD, 'second waveguide cladding')
        EC_CLAD = Layer(PROCESS.EC_CLAD, PURPOSE.COR, 'EC_CLAD')
        HTR = Layer(PROCESS.HTR, PURPOSE.COR, 'HTR')
        METAL = Layer(PROCESS.METAL, PURPOSE.COR, 'METAL')
        LABEL_NOTE = Layer(PROCESS.LABEL, PURPOSE.NOTE, 'Label, used for PhotoCAD')
        TEXT_NOTE = Layer(PROCESS.TEXT, PURPOSE.NOTE, 'Text layer, not to print on wafer, used for PhotoCAD')
        DTR = Layer(PROCESS.DTR, PURPOSE.COR, 'DTR')
        PINREC_NOTE = Layer(PROCESS.PINREC, PURPOSE.NOTE, 'Pin rectangle, for LVS, DRC, used for PhotoCAD, core definition')
        PINREC_CLAD = Layer(PROCESS.PINREC, PURPOSE.MARK, 'Pin rectangle, for LVS, DRC, used for PhotoCAD, cladding definition')
        FLYLINE_MARK = Layer(PROCESS.FLYLINE, PURPOSE.MARK, 'Flyline for insufficient space in AutoLink, used for PhotoCAD')
        ERROR_MARK = Layer(PROCESS.ERROR, PURPOSE.MARK, 'Error mark, used for PhotoCAD')
        BB = Layer(PROCESS.BB, PURPOSE.COR, 'Define blackbox')
        BB_LABEL = Layer(PROCESS.BB, PURPOSE.NOTE, 'Define blackbox label')
        BLOCK = Layer(PROCESS.BLOCK, PURPOSE.MARK, 'BLOCK')



For users using layout viewers (e.g. KLayout), they can import the layer properties file ``layers.lyp`` in ``technology/generated`` file folder.
